# 보안 정책 / Security Policy

## 지원되는 버전 / Supported Versions

이 섹션에서는 현재 보안 업데이트가 지원되는 프로젝트의 버전에 대해 설명합니다.  
This section tells you about which versions of your project are currently being supported with security updates.

| 버전 / Version | 지원됨 / Supported         |
| -------------- | -------------------------- |
| 5.1.x         | :white_check_mark:        |
| 5.0.x         | :x:                       |
| 4.0.x         | :white_check_mark:        |

## 취약점 보고 / Reporting a Vulnerability

이 섹션에서는 취약점을 보고하는 방법에 대해 설명합니다.  
This section tells you how to report a vulnerability.

- **보고 방법 / How to Report**: 취약점을 보고하려면 [이 링크](#)를 방문하세요.  
  To report a vulnerability, please visit [this link](#).
- **업데이트 주기 / Update Frequency**: 보고된 취약점에 대한 업데이트는 매주 제공됩니다.  
  Updates on reported vulnerabilities are provided weekly.
- **결과 기대 / Expected Outcome**: 취약점이 수락되면 패치 일정과 함께 후속 조치를 안내합니다.  
  If the vulnerability is accepted, you will be informed of the patch schedule and follow-up actions. 취약점이 거부될 경우, 그 이유를 설명하는 피드백을 드립니다.  
  If the vulnerability is declined, you will receive feedback explaining the reason.
